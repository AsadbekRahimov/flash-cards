# Руководство по панелям LexiFlow Pro (PDF)

Исходники руководства для ролей панелей `/admin` и `/org` (все роли, кроме ученика Mini App).

- `parts/*.html` — главы (фрагменты HTML, без `<html>`/`<body>`), собираются по порядку имён файлов.
- `img/<глава>/*.png|jpg` — снимки экранов со стенда с демонстрационными данными.
- `guide.css` — оформление, `build.mjs` — сборка PDF через Playwright (Chromium).
- Результат: `LexiFlow_Panels_Guide_RU.pdf`.

## Правила для глав
- Язык — русский, обращение на «вы», короткие предложения, без жаргона разработчиков.
- Каждая глава: `<section class="chapter" id="...">` с `<h1>`; разделы `<h2>`, шаги `<ol class="steps">`.
- Снимок: `<figure><img src="../img/<глава>/<файл>" alt="..."><figcaption>Рис. N. …</figcaption></figure>`; подпись говорит, что на снимке и куда смотреть.
- Врезки: `<div class="note">` (к сведению), `<div class="warn">` (осторожно: необратимо, деньги, доступ).
- Таблицы — только для перечислимых фактов (поля формы, статусы, права ролей).
- Только то, что реально есть в интерфейсе стенда: каждое утверждение проверено на экране или в коде.
- Данные на снимках — демонстрационные, без настоящих людей, телефонов, токенов и секретов.
