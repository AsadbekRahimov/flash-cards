# LexiFlow Pro: как учить слова, чтобы помнить долго и уметь применять

Исследование методов запоминания лексики и рекомендации для продукта. Дата: 10.11.2026.

## 0. Главное за минуту

1. **Сильнее всего доказаны две вещи: вспоминание (retrieval practice) и разнесение во времени (spacing).** Обе в продукте уже есть. Это фундамент, его менять не надо.
2. **Слабое место продукта — не расписание, а то, ЧТО ученик делает с карточкой.** Основная карточка (`flash`) — это «посмотрел → сам себе поставил оценку». Задания, где ответ проверяется объективно и слово нужно произвести (написать, вставить в предложение), выдаются редко и только в Pro. Практика (сочетания, предложения, диктант) с расписанием повторений не связана.
3. **Мнемоника (keyword method) работает, но уже, чем принято думать.** Она ускоряет первое запоминание «форма → значение», особенно для конкретных существительных. Для активного употребления она помогает хуже простого повторения, а отложенный эффект в исследованиях неоднозначен. Вывод: мнемоника — это «крючок» для первого знакомства и для слов, которые не идут, а не основа метода.
4. **«Свободно применять» даёт не мнемоника, а продукция и разные контексты.** Нужно, чтобы слово по мере созревания проходило лестницу: узнал → вспомнил перевод → вспомнил само слово → написал → вставил в чужое предложение → составил своё.
5. **Курс сейчас устроен против одного из выводов исследований:** уроки собраны из семантически близких слов (mother/father/sister/brother; young/old, tall/short; you/he/she/it). Такие наборы чаще путаются между собой.
6. **Оговорка о проверке источников.** В этой сессии сеть разрешает только поиск и GitHub. Сайты издательств (Wiley, Cambridge, Springer, SAGE, PubMed и др.) открыть не удалось. Поэтому большинство утверждений ниже опирается на аннотации и выдержки из результатов поиска, а не на прочитанные полные тексты. Напрямую открыты и прочитаны только: руководство Anki (исходники на GitHub), README `srs-benchmark` и учебник FSRS. Раздел 5 перечисляет, что именно не подтверждено.

## 1. Что продукт делает сегодня

### 1.1 Расписание повторений

- **Алгоритм:** SM-2 + минутные шаги в стиле Anki (`SpacedRepetitionEngine`, `LearningStepMachine`). Шаги заучивания 1 и 10 минут, выпуск на 1 день (на 4 дня при «Легко»), далее 1 → 6 → `interval × EF`. Потолок интервала 3650 дней.
- **Оценка:** три кнопки — «Трудно» (q=2, провал), «Средне» (q=4), «Легко» (q=5). Ученик ставит её себе сам.
- **FSRS-5** реализован рядом как A/B (`FsrsScheduler`), целевое удержание 0.9, веса по умолчанию. `FSRS_ROLLOUT_PERCENT` по умолчанию 0, то есть все на SM-2.
- **Трудные слова:** флаг `is_hard` ставится при провале и снимается первым успешным дневным повторением. Эффект: такие карточки идут первыми в очереди и дают бонус на экзамене. Счётчик `lapses` ведётся, но используется только в аналитике и для «босса» в игре. **Особого обращения с «пиявками» (leeches) нет** — слово, проваленное 8 раз, получает то же самое в девятый.
- **Объём:** дневная цель 10 / 20 / 40 оценок, бесплатно 20 новых слов в день, лимит 200 оценок на сессию.

### 1.2 Типы упражнений

`ExerciseSelector` выбирает тип так:

| Условие | Что выдаётся |
|---|---|
| Слово не выпущено или `repetitions < 2` | `flash` (самооценка) |
| Далее, по хэшу от `repetitions:word_id` | ротация `flash` / `reverse` (выбор английского слова из 4) / `audio` (выбор перевода из 4 на слух) |
| Pro, каждое третье повторение начиная с третьего | `gap_fill` (вписать слово в пример) или `spelling` (написать слово) — проверяет сервер |

Что из этого следует:

- Порядок типов **случайный, а не возрастающий по сложности**.
- `reverse` и `audio` — это узнавание из четырёх вариантов.
- Вспоминание с вводом ответа (`spelling`, `gap_fill`) — только Pro и только каждое третье повторение. Бесплатный ученик никогда не пишет слово в основном цикле.
- Новое слово показывается сразу с переводом и примером (попытки угадать нет).

### 1.3 Практика, игра, свои колоды

- **Практика** (`app/Domain/Practice`): пары, сочетания (выбор предлога и т. п.), сборка предложения из фрагментов, диктант. У авторских заданий есть объяснение на ru/uz. **Практика намеренно изолирована: она не пишет в `word_repetitions`.**
- **Игра «Караван»:** ошибка приближает повторение слова, верный ответ ничего не меняет. Это грамотное решение.
- **Свои колоды:** 1 колода на 50 слов бесплатно, 20 колод по 2000 слов в Pro.
- **«Говорим»** (голосовая практика) — отложено владельцем.

### 1.4 Модель слова

Таблица `words`: `word`, `translation`, `example` (один), `part_of_speech`, `transcription`, `audio_path`, `meta` (jsonb). Таблица `word_translations`: перевод и перевод примера на каждую локаль.

В данных курса (`database/data/courses/english-a1-a2`, 1000 слов) заполнены: слово, часть речи, перевод ru/uz, один пример с переводом. Поле `transcription` в JSON курса отсутствует.

**Нет:** картинки, мнемоники/ассоциации (ни авторской, ни своей), нескольких примеров, сочетаний на уровне слова, семьи слов, пометки «ложный друг», пометки о путаемых парах.

### 1.5 Что из доказанного есть, а чего нет

| Приём | Статус |
|---|---|
| Разнесённое повторение | Есть (SM-2, FSRS готов) |
| Вспоминание вместо перечитывания | Есть, но в основном на самооценке |
| Доучивание до критерия внутри сессии + повтор в следующих (successive relearning) | Есть (минутные шаги + дневные интервалы) |
| Звук слова | Есть (TTS, кнопка) |
| Объяснение после ошибки | Есть в практике, нет в карточках |
| Объективная проверка ответа | Частично: Pro, каждое третье повторение |
| Продукция слова (написать) | Частично: Pro |
| Слово в предложении | Частично: один пример; `gap_fill` в Pro; практика отдельно |
| Несколько разных контекстов | Нет |
| Своё предложение | Нет |
| Мнемоника / «крючок» | Нет |
| Картинка | Нет |
| Проговаривание вслух | Нет (кнопка «послушать» есть, шага «скажи» нет) |
| Семьи слов, морфология | Нет |
| Лечение «пиявок» | Нет |
| Разведение путаемых слов | Нет, и уроки собраны наоборот |
| Попытка угадать до показа | Нет |
| Целевое удержание как настройка | Только в конфиге FSRS |

## 2. Что говорит наука

Шкала силы доказательств: **сильные** (мета-анализы, много повторений результата), **средние** (несколько хороших исследований, есть оговорки), **слабые** (мало работ, противоречия или только лаборатория).

### 2.1 Разнесение, интервалы, SM-2 и FSRS

- **Разнесение лучше зубрёжки подряд — сильные доказательства, и именно для L2.** Мета-анализ Kim & Webb (2022, *Language Learning*): 98 эффектов из 48 экспериментов, эффект от среднего до большого. По вторичной цитате g ≈ 0.58 на немедленном тесте и ≈ 0.80 на отложенном — цифры по полному тексту не сверены. [Источник](https://www.bohrium.com/en/paper-details/the-effects-of-spaced-practice-on-second-language-learning-a-meta-analysis/813033326355939328-6763)
- **Расширяющиеся интервалы против равных — разницы нет.** Тот же мета-анализ: статистически эквивалентны. Nakata (2015) пришёл к тому же. Важна не форма графика, а сам факт разнесения; более длинные промежутки лучше для отложенного теста. [Nakata 2015](https://resolve.cambridge.org/core/journals/studies-in-second-language-acquisition/article/effects-of-expanding-and-equal-spacing-on-second-language-vocabulary-learning/D1D796306985C52F9BE7A1200AC50DB9)
- **Оптимальный промежуток зависит от того, на сколько нужно запомнить.** Cepeda и др. (2008): примерно 20–40 % от срока при проверке через неделю и 5–10 % при проверке через год. [PubMed](https://pubmed.ncbi.nlm.nih.gov/19076480/)
- **FSRS против SM-2.** В открытом бенчмарке (около 10 тыс. коллекций Anki, ~350 млн оценок) FSRS-5 и FSRS-6 предсказывают вероятность вспомнить заметно точнее, чем простые модели: log loss 0.356 и 0.346 против 0.469 у HLR (модель Duolingo). [srs-benchmark](https://github.com/open-spaced-repetition/srs-benchmark). Руководство Anki говорит, что при том же удержании повторений нужно меньше; популярные цифры «на 20–30 % меньше» встречаются только в блогах, в первичном источнике я их не нашёл. Сила: **средняя** — данные большие, но это точность предсказания на пользователях Anki, а не эксперимент с исходом «выучил больше».
- **Что FSRS улучшает по сути:** явная цель удержания; нет «ease hell» (сложность возвращается к среднему); корректно учитывает повторение раньше или позже срока. [Учебник FSRS](https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md)
- **Целевое удержание.** Руководство Anki: по умолчанию 90 %, это «хороший баланс»; выше 90 % нагрузка растёт очень быстро, выше 97 % становится непосильной. Учебник FSRS называет разумным диапазон 80–95 %. [Deck options](https://github.com/ankitects/anki-manual/blob/main/src/deck-options.md)
- **Потолок интервала.** В Anki по умолчанию 100 лет; уменьшение — это обмен времени на удержание. Научного «правильного» значения нет.
- **Персональное расписание даёт реальный выигрыш.** Lindsey и др. (2014), школьники: +16.5 % к удержанию против массированного повторения и +10 % против одинакового для всех разнесённого. [PDF](https://home.cs.colorado.edu/~mozer/Research/Selected%20Publications/reprints/LindseyShroyerPashlerMozer2014.pdf). Duolingo (Settles & Meeder, 2016): обучаемая модель дала +12 % к ежедневной вовлечённости. [ACL](https://preview.aclanthology.org/landing_page/P16-1174)

### 2.2 Вспоминание, узнавание, трудности, обратная связь

- **Вспоминание сильнее перечитывания — сильные доказательства.** Karpicke & Roediger (2008, пары суахили–английский): повторное тестирование дало большой эффект на отложенном тесте, повторное чтение — нет. [Источник](https://profiles.wustl.edu/en/publications/the-critical-importance-of-retrieval-for-learning/). Dunlosky и др. (2013) ставят practice testing в высшую категорию полезности.
- **Вспомнить или узнать из вариантов.** Nakata (2016): форматы с вспоминанием лучше формируют продуктивное знание написания; узнавание полезно для части других исходов. [Источник](https://www.degruyterbrill.com/document/doi/10.1515/iral-2015-0022/html?lang=en). Прямого мета-анализа «ввод с клавиатуры против выбора из вариантов» для L2-лексики я не нашёл. Сила: **средняя**.
- **Сколько раз вспоминать за сессию.** Nakata (2017): 5 и 7 вспоминаний лучше, чем 1 и 3; между 5 и 7 разницы нет (по вторичному пересказу). [Источник](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/does-repeated-practice-make-perfect-the-effects-of-withinsession-repeated-retrieval-on-second-language-vocabulary-learning/F14BA8A576CD2563D14CEA46E35D842E)
- **Желательные трудности (Bjork).** Условия, при которых учиться труднее и ошибок больше (разнесение, тест, перемешивание), часто дают лучшее долгое запоминание; успех во время занятия — ненадёжный показатель выученного. [Soderstrom & Bjork 2015](https://hwb.gov.wales/api/storage/1031b700-acaf-4eda-a4bc-758715e85ff2/Learning%20versus%20Performance%20An%20Integrative%20Review.pdf). Практический смысл: лёгкая сессия с 98 % верных ответов — плохой признак.
- **Гиперкоррекция.** Ошибки, в которых человек был уверен, после исправления запоминаются лучше, но через неделю часть возвращается. [PubMed](https://pubmed.ncbi.nlm.nih.gov/21989771/). Смысл: показывать верный ответ обязательно, а исправленное слово вскоре спросить ещё раз.
- **Немедленная или отложенная обратная связь.** Nakata (2015): для L2-лексики при честном контроле разницы почти нет. [Источник](https://researchmap.jp/nakatata/published_papers/735164?lang=en). Значит, немедленный показ ответа — нормально.

### 2.3 Мнемоника

- **Метод ключевых слов (Atkinson & Raugh, 1975).** Иностранное слово связывают с похожим по звучанию словом родного языка и образом, соединяющим его со значением. В исходном опыте (120 русских слов для англоязычных) метод оказался эффективным; точные проценты я подтвердить не смог. [eScholarship](https://escholarship.org/uc/item/5gb7g0zc)
- **Когда помогает:** быстрое первое запоминание, рецептивное знание (увидел слово → вспомнил значение), конкретные слова с образом. Ellis & Beaton (1993): ключевые слова хороши для рецептивного знания, **для произнесения и написания слова лучше простое повторение**; лучший результат — при сочетании обоих; ключевые слова-существительные помогают, глаголы мешают. [PDF](https://public.websites.umich.edu/~ncellis/NickEllis/Publications_files/Ellis%26BeatonLL1993.pdf)
- **Когда выдыхается.** Wang & Thomas (1992, 1995): забывание после мнемоники шло быстрее, чем после заучивания. McDaniel, Pressley & Dunay (1987): преимущество в начале, без разницы в долгом удержании. [Источник](https://profiles.wustl.edu/en/publications/long-term-retention-of-vocabulary-after-keyword-and-context-learn/). Есть и работы с положительным отложенным эффектом. Сила для долгого удержания: **слабая, противоречивая**.
- **Оценка Dunlosky и др. (2013): низкая полезность** — наряду с перечитыванием и выделением маркером. Причины: узкая применимость и сомнительная долговечность. [Аннотация](https://www.citedrive.com/en/discovery/improving-students-learning-with-effective-learning-techniques)
- **Готовая или своя ассоциация.** Результаты смешанные: готовые экономят время и чаще выигрывают на немедленном тесте; многие школьники не умеют придумывать удачные ключевые слова. [Источник](https://revistas.ucm.es/index.php/SJOP/article/download/SJOP0202220102A/29337/30498). Разумный вариант — дать готовую и предложить заменить своей.
- **Важно для нас:** все эти опыты сравнивали мнемонику с зубрёжкой **без** разнесённого повторения. Мнемоника в связке с SRS изучена плохо. Логика связки такая: мнемоника даёт быстрый первый успех, SRS гасит её быстрое выцветание. Это гипотеза, её надо проверять на своих данных.
- **Дворец памяти (method of loci).** Мета-анализ Twomey & Kroneisen (2021): g = 0.65 по 13 исследованиям, но высокий риск смещения. [Источник](https://pmc.ncbi.nlm.nih.gov/articles/PMC12514325/). Метод рассчитан на список по порядку и требует тренировки; для тысяч слов с переводом и употреблением он не подходит. **В продукт не брать.**
- **Крючки-цифры (peg), истории-цепочки.** Та же природа: хороши для упорядоченных списков. Данных именно по L2-лексике я не нашёл. **Не брать.**
- **Морфология и семьи слов.** Мета-анализы Goodwin & Ahn: обучение морфологии даёт средний эффект (d ≈ 0.32) на грамотность у школьников; обзор по L2 сообщает о стабильном приросте словаря. [Обзор](https://link.springer.com/article/10.1007/s10648-024-09953-3). Сила: **средняя**. В отличие от мнемоники, это переносимое знание: `un-`, `-er`, `-ful`, `-less` работают на сотнях слов.
- **Когнаты и ложные друзья.** Для русскоязычных общих с английским слов много (интернационализмы), и они узнаются почти бесплатно; ложные друзья (magazine, accurate, artist) дают устойчивые ошибки. [Обзор Easton](https://evaeaston.com/rel/rel1.html), [казахстанское исследование](https://philart.kaznu.kz/index.php/1-FIL/article/download/143/141/281). По узбекскому нашлись только описательные работы о заимствованиях, экспериментов с учениками нет. Сила: **слабая для узбекского**.

### 2.4 Глубина обработки

- **Involvement Load Hypothesis (Laufer & Hulstijn).** Мета-анализ Yanagisawa & Webb (2021), 42 исследования: гипотеза объясняет 15 % разброса на немедленном тесте и 5 % на отложенном. Больше всего даёт компонент **evaluation** (сравнить слово с другими, решить, подходит ли оно в контекст), затем need; search вклада не дал. [Источник](https://zendy.io/title/10.1111/lang.12444). Сила: **средняя, эффект скромный**.
- **Technique Feature Analysis (Nation & Webb, 2011).** Hu & Nassaji (2016): предсказывает результат лучше, чем ILH. [Источник](https://eld.bl.uk/catalog/100068936491_0x000001). Полезна как чек-лист для упражнения: есть ли вспоминание, генерация, обратная связь, мотивация.
- **Эффект генерации.** Мета-анализ Bertsch и др. (2007): d = 0.40 по 86 исследованиям — то, что породил сам, помнится лучше, чем прочитанное. [PDF](https://mcdaniel97.github.io/Publications/Bertsch%20et%20al.%202007.pdf)
- **Связь с собой (self-reference).** Мета-анализ Symons & Johnson (1997): информация, привязанная к себе, помнится лучше (эффект около 0.45 по вторичному источнику). [Источник](https://www.bohrium.com/paper-details/the-self-reference-effect-in-memory-a-meta-analysis/812136903573766145-7180)
- **Важное предостережение про «своё предложение».** Barcroft (2004): когда слово **новое**, задание написать с ним предложение дало сильный **отрицательный** эффект на запоминание формы по сравнению с простыми повторами. Объяснение: ресурсы уходят на смысл, на форму не остаётся. [Источник](https://profiles.wustl.edu/en/publications/effects-of-sentence-writing-in-second-language-lexical-acquisitio/). При этом Webb (2005) показал: когда на письмо даётся больше времени, продуктивные задания выигрывают. [Источник](https://www.cambridge.org/core/product/DDF362AE7B13D1949B1CD591DA2F3414). Вывод: **своё предложение — для уже знакомых слов, не для первого знакомства.**

### 2.5 Образы, звук, проговаривание, жест

- **Картинки.** Теория двойного кодирования (Paivio) популярна, но данные по L2 смешанные: в ряде опытов картинка не лучше перевода на тесте «вспомни L2-слово», а иногда отвлекает от формы. Для конкретных слов у начинающих польза есть. Сила: **слабая–средняя**. Точную ссылку на первичное исследование (Carpenter & Olson, 2012) открыть не удалось.
- **Эффект проговаривания (production effect).** Слова, прочитанные вслух, помнятся лучше прочитанных про себя; в исследовании билингвов эффект оказался **больше на втором языке**. [PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11111515/). Сила: **средняя**. Оговорка: эффект сильнее, когда вслух читается часть слов, а не все.
- **Жест (enactment).** Работы Macedonia: слова, выученные с жестом, помнятся лучше, в том числе через 60 дней. [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4260465). Почти всё от одной группы, малые выборки. В мобильном приложении реализовать трудно. Сила: **слабая**; не брать.

### 2.6 Контекст и перенос

- **Что значит знать слово (Nation).** Три стороны — форма, значение, употребление; у каждой рецептивная и продуктивная часть. Употребление включает грамматические шаблоны и сочетаемость. [Источник](https://resolve.cambridge.org/core/books/abs/learning-vocabulary-in-another-language/knowing-a-word/11C16210DBC513BC703EB530D52803C5). Карточка «слово — перевод» покрывает одну ячейку из девяти.
- **Пары или предложения.** Изолированные пары — быстрый способ связать форму и значение; это не спорно. Но знание сочетаемости и грамматики слова из пар не возникает. Исследование Webb (2007) о сравнении пар и предложений с глоссой я нашёл только как библиографическую запись — его результат не подтверждён.
- **Четыре направления (four strands, Nation).** Курс должен примерно поровну делить время между вводом со смыслом, выводом со смыслом, целенаправленным изучением языка и беглостью. [Источник](https://en.wikipedia.org/wiki/Paul_Nation). Карточки — это только третье направление, то есть около четверти.
- **Сколько встреч нужно.** Мета-анализ Uchihara, Webb & Yanagisawa (2019): связь числа встреч со случайным запоминанием средняя, r = 0.34. [Источник](https://zendy.io/title/10.1111/lang.12343). Единого порога нет; расхожее «10–12 встреч» — ориентир, а не закон.
- **Разные контексты.** Bolger и др. (2008): разные предложения лучше одного повторяемого для усвоения значения. [PDF](https://www.lrdc.pitt.edu/perfettilab/pubpdfs/Context%20variation%20Bolger%20et%20al.pdf). Более новые работы уточняют: разнообразие помогает **переносу в новые контексты**, но на раннем этапе может мешать; сначала слово лучше «заякорить» в одном контексте. [PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10280660/), [Li и др. 2023](https://discovery.ucl.ac.uk/10182544/). Сила: **средняя**. Вывод: один пример на старте, новые примеры — после выпуска карточки.
- **Сочетания (collocations).** Обзоры Boers: результаты обучения сочетаниям смешанные; простое «обращение внимания» даёт мало; сочетания, не совпадающие с родным языком, усваиваются труднее всего и требуют отдельной тренировки. [Обзор](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/A950F8F80BDD64E02D3F6052BA705478/S0261444817000301a.pdf/teaching-and-learning-collocation-in-adult-second-and-foreign-language-learning.pdf)
- **Продуктивное знание отстаёт от рецептивного и само не вырастает.** Тренировка в направлении L1 → L2 нужна отдельно (Webb 2005; Ellis & Beaton 1993).

### 2.7 Перемешивание, семантические наборы, размер порции

- **Семантические наборы мешают.** Tinkham (1993, 1997), Waring (1997), Erten & Tekin (2008): слова одной категории, выученные вместе, учатся медленнее. [Обзор](https://jalt-publications.org/sites/default/files/pdf-article/38.5tlt_sig9.pdf). Nakata & Suzuki (2019): итоговые баллы не отличались, но **ошибок-перепутываний было больше**. [Источник](https://www.cambridge.org/core/product/F58BA8D70385603B9C42E408BFCB8A10). Сила: **средняя**, новые работы дают смешанную картину.
- **Тематические наборы — нормально.** Слова одной сцены, но разных категорий и частей речи (frog, pond, green, jump) не мешают друг другу (Tinkham 1997).
- **Перемешивание (interleaving).** Для грамматики данные есть, для лексики — скудные и противоречивые. [Pan и др.](https://sc-pan.github.io/pdf/PLPR_2019.pdf). SRS и так перемешивает слова; отдельной фичи не нужно.
- **Размер порции.** Nakata & Webb (2016): при одинаковом разнесении неважно, учить 20 слов разом или по 4; **важно разнесение, а не размер набора**. [Источник](https://resolve-he.cambridge.org/core/journals/studies-in-second-language-acquisition/article/does-studying-vocabulary-in-smaller-sets-increase-learning/E17B75ABAE1300734AF014C363D59FBC). Научно обоснованного «N новых слов в день» нет; ограничитель — нагрузка повторений через 2–3 недели.

### 2.8 Сон, короткие сессии, привычка

- **Сон.** Gais и др. (2006): слова, выученные вечером, забывались меньше, чем выученные утром. [Обзор](https://www.merrimack.edu/wp-content/uploads/Sleep-and-Word-Learning.pdf). Mazza и др. (2016): учить вечером и доучивать утром — быстрее переучивание и лучше удержание, преимущество сохранялось через 6 месяцев. [APS](https://www.psychologicalscience.org/news/releases/sleep-makes-relearning-faster-and-longer-lasting.html), [BPS](https://www.bps.org.uk/research-digest/faster-learning-and-longer-retention-interleave-study-sessions-sleep). Сила: **средняя**, выборки малые.
- **Серии (streaks).** Исследование в *Journal of Consumer Research* (в пересказе INSEAD): серии действительно мотивируют; разрыв серии демотивирует, особенно когда человек винит себя; возможность «починить» серию снижает её ценность. [INSEAD](https://knowledge.insead.edu/marketing/consumer-streaks-are-motivating-the-key-is-keeping-them-alive-19011)
- **Геймификация.** Hanus & Fox (2015), 71 студент, 16 недель: в курсе с бейджами и таблицей лидеров мотивация и удовлетворённость со временем **упали**. Это учебная аудитория, не приложение. Сила: **слабая**. Данных о «тревоге из-за серии» в рецензируемых работах я не нашёл — только блоги.

### 2.9 Successive relearning и рейтинг Dunlosky

- **Successive relearning (Rawson & Dunlosky).** Вспоминать до первого верного ответа, затем повторять то же в нескольких разнесённых сессиях. В учебных курсах — прибавка около одной буквенной оценки; три разнесённые сессии против трёх повторов в одной: 68 % против 26 %. [Обзор 2022](https://journals.sagepub.com/doi/full/10.1177/09637214221100484), [пересказ](https://www.retrievalpractice.org/archive/2018/successive-relearning). **Это ровно то, что делают минутные шаги плюс дневные интервалы.**
- **Dunlosky и др. (2013), 10 приёмов.** Высокая полезность: тестирование, разнесённая практика. Средняя: объяснение «почему», самообъяснение, перемешивание. Низкая: конспект-резюме, выделение, **ключевые слова-мнемоника**, образы для текста, **перечитывание**. [Аннотация](https://www.citedrive.com/en/discovery/improving-students-learning-with-effective-learning-techniques)

### 2.10 Ошибки, предтест, метапознание

- **Предтест (угадай до показа).** Potts & Shanks (2014): попытка угадать перевод незнакомого слова перед показом ответа улучшила запоминание, даже когда догадка была неверной. [Источник](https://westminsterresearch.westminster.ac.uk/item/8y95x/the-benefit-of-generating-errors-during-learning). Но повторения показали выигрыш только на тесте узнавания, не на вспоминании. [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC8673917). Сила: **слабая–средняя**.
- **Самооценка ненадёжна.** Koriat & Bjork: когда ответ перед глазами, кажется, что «я это знал» (foresight bias). [PDF](https://sites.lifesci.ucla.edu/psych-bjorklab/wp-content/uploads/sites/13/2016/07/Koriat_Bjork_2006_MC.pdf). Kornell & Bjork: ученики слишком рано откладывают карточки как «выученные». [PDF](https://sites.lifesci.ucla.edu/psych-bjorklab/wp-content/uploads/sites/13/2016/07/Kornell_RBjork_2007.pdf). Прямого исследования «насколько снисходительно люди оценивают себя на карточках» я не нашёл.
- **Последствие для расписания.** Руководство Anki прямо предупреждает: если нажимать «с трудом вспомнил», когда на деле забыл, все интервалы FSRS станут завышенными. Самооценка — входной сигнал алгоритма; если она врёт, расписание врёт.

### 2.11 «Пиявки»

- Руководство Anki: карточка с 8 провалами помечается как leech; **«самый эффективный способ — изменить подачу материала»**, некоторым карточкам помогает мнемоника; частая причина — путаница двух похожих слов, тогда одно стоит отложить, пока не закрепится другое. [Leeches](https://github.com/ankitects/anki-manual/blob/main/src/leeches.md)
- Это практика сообщества, а не эксперимент. Но она согласуется с данными о семантической интерференции и о мнемонике как средстве для трудных пар. Сила: **слабая (экспертная)**, риск низкий.

### 3.1 Лестница упражнений по зрелости слова — высокое / M

- **Что видит ученик.** Слово проходит ступени, а не случайную ротацию:
  1. знакомство (карточка с переводом, примером, звуком, крючком);
  2. узнавание: выбрать перевод на слух или из вариантов;
  3. вспоминание значения: увидел слово → назвал перевод (самооценка);
  4. вспоминание слова: увидел перевод → выбрал, затем **написал** слово;
  5. слово в контексте: вписать в пример (`gap_fill`), затем в **новый** пример;
  6. употребление: сочетание, сборка предложения, своё предложение.
  Ошибка опускает на ступень ниже.
- **Почему.** Продуктивное знание не возникает из рецептивного (Ellis & Beaton; Webb 2005); вспоминание сильнее узнавания для продукции (Nakata 2016); порядок «сначала форма и значение, потом контекст» следует из Barcroft (2004) и работ о якорении.
- **Что есть в коде.** `ExerciseSelector` — чистая функция от `repetitions` и `state`; все типы карточек уже существуют. Нужна замена хэш-ротации на функцию от зрелости (например, от `interval_days` или `stability`).
- **Риски.** Сессии станут длиннее и труднее; часть учеников уйдёт от ввода с клавиатуры. Смягчение: допуск опечаток уже есть в `SpellingGrader`.
- **Как измерить.** A/B: доля верных ответов на `spelling` и `gap_fill` для слов возрастом 30+ дней; удержание D7 и D30 как защитная метрика.

### 3.2 Объективная проверка вместо части самооценок — высокое / S–M

- **Что видит ученик.** На зрелых словах часть повторений — не «оцени себя», а ввод или выбор, где оценку ставит сервер.
- **Почему.** Самооценка смещена (Koriat & Bjork), а она — вход расписания. Сейчас у бесплатного ученика расписание целиком построено на самооценке.
- **Что есть.** `spelling` и `gap_fill` с серверной оценкой работают, но закрыты фичами `exercise.spelling` и `exercise.gap_fill` (Pro).
- **Риск — коммерческий.** Это решение владельца: открыть ли хотя бы одно объективное упражнение в Free. Довод «за»: без него метод в бесплатной версии — это именно «зубрёжка + SRS», от которой продукт хочет уйти.
- **Как измерить.** Расхождение между самооценкой и следующим объективным ответом по тому же слову. Если после «Легко» ученик не может написать слово в 40 % случаев — это число покажет масштаб проблемы уже на текущих данных Pro.

### 3.3 Лечение «пиявок» — высокое / M

- **Что видит ученик.** Слово, проваленное N раз (начать с `lapses >= 4`), перестаёт приходить в прежнем виде. Вместо этого экран «Это слово не идёт. Давай по-другому»: крючок памяти (готовый или просьба придумать свой), новый пример, если есть путаемое слово-сосед — оба рядом с объяснением разницы. Затем слово возвращается в расписание.
- **Почему.** Больше одинаковых повторений не помогает; менять надо подачу (руководство Anki). Мнемоника полезнее всего именно для трудных пар.
- **Что есть.** `lapses` считается; `BossWordPicker` уже ранжирует по `is_hard` и `lapses`; в docs/06 §10 leech-detection записан как будущая задача.
- **Риски.** Без контента (№ 4, № 5) экран будет пустым — тогда хотя бы поле «своя ассоциация» и показ слова учителю.
- **Как измерить.** Доля «пиявок», переживших следующий интервал 7+ дней, до и после.

### 3.4 «Крючок памяти» — среднее–высокое / M код, L контент

- **Что видит ученик.** На первой карточке слова и на экране «пиявки» — строка «Как запомнить»: короткая ассоциация на его языке. Кнопка «Свой вариант» сохраняет личный крючок, он показывается вместо авторского.
- **Какие крючки писать, по убыванию ценности:**
  1. **морфологический разбор** (`un + happy`, `teach → teacher`) — переносимое знание;
  2. **знакомое слово** (интернационализм, заимствование в русском или узбекском);
  3. **звуковая ассоциация с образом** (классический keyword) — для конкретных существительных;
  4. для глаголов и абстрактных слов keyword чаще мешает (Ellis & Beaton) — там лучше яркий пример или сочетание.
- **Почему.** Ускоряет первое запоминание и рецептивное знание; долгий эффект берёт на себя SRS.
- **Что нужно.** Поля: авторский крючок по локалям (в `word_translations` или `words.meta`), личный крючок ученика (новая таблица — изменение схемы, по правилам проекта это задача для architect).
- **Риски.** Узбекские звуковые ассоциации может писать только носитель; машинный перевод русских крючков не работает в принципе (ассоциация звуковая). 1000 слов × 2 языка — большой объём. Плохой крючок хуже отсутствия. Не обещать пользователям «запомнишь навсегда благодаря ассоциациям» — наука этого не подтверждает.
- **Как начать дёшево.** Только поле «своя ассоциация» + авторские крючки для 100–150 слов с наибольшей долей провалов (метрика «трудное слово для группы» в docs/06 §8 уже есть).
- **Как измерить.** A/B по словам: доля провалов на первом дневном повторении и число повторений до интервала 21 день; отдельно — точность `spelling` (проверить, что продукция не пострадала).

### 3.5 Несколько примеров и их ротация — высокое / S код, L контент

- **Что видит ученик.** До выпуска карточки — всегда один и тот же пример. После — на каждом повторении другой; `gap_fill` на зрелом слове использует предложение, которого ученик ещё не видел.
- **Почему.** Разные контексты нужны для переноса; на раннем этапе разнообразие мешает (Bolger 2008; Li и др. 2023). Сейчас `gap_fill` всегда по одному предложению — ученик запоминает предложение, а не слово.
- **Что нужно.** Таблица примеров слова (изменение схемы) и ещё 2–3 предложения на слово с переводами ru/uz. Часть уже есть: предложения из `practice_items` привязаны к целевым словам через `practice_item_words`.
- **Риски.** Объём контента; предложения должны быть из уже пройденной лексики.
- **Как измерить.** Точность `gap_fill` на **невиданном** предложении — это и есть прямая метрика «умеет применять».

### 3.6 Не вводить путаемые слова в один день — среднее / M

- **Что видит ученик.** Ничего особенного: просто mother и father, tall и short, he и she приходят как новые в разные дни.
- **Почему.** Семантические наборы дают больше перепутываний (Tinkham; Waring; Nakata & Suzuki 2019).
- **Что есть.** `CardPicker` выдаёт новые слова строго в порядке `(stage, lesson, words.id)`, а уроки — это семантические наборы по 10 слов.
- **Варианты.** Дешёвый: в существующих уроках поменять порядок слов так, чтобы антонимы и ближайшие соседи не шли подряд, и не выдавать больше 5 новых слов одного урока в день. Полный: разметка «путается с» и правило в пикере. Перекраивать курс в тематические уроки — дорого, и доказательства этого не требуют.
- **Риски.** Групповые уроки с учителем идут по уроку целиком — правило применять только к личным режимам.
- **Как измерить.** Доля ошибок в `reverse`/`audio`, где выбран дистрактор из того же урока.

### 3.7 FSRS по умолчанию и цель удержания — среднее / S

- **Что делать.** Довести A/B до решения (виджет SM-2 vs FSRS уже есть), затем включить FSRS новым ученикам. Цель удержания оставить 0.9; дать выбор из трёх режимов («спокойный» 0.85, «обычный» 0.9, «к экзамену» 0.93–0.95) вместо числа.
- **Почему.** Точнее предсказывает забывание; нет «ease hell»; корректно учитывает досрочные повторения (а игра их создаёт). Выигрыш в числе повторений вероятен, но его размер для нас неизвестен.
- **Оговорка.** Веса по умолчанию обучены на пользователях Anki — в основном взрослых с самооценкой. Свои веса — когда накопится достаточно оценок (в docs/06 записано 100k+).
- **Важно.** FSRS не сделает слова «применимыми». Это оптимизация времени, а не метода.
- **Как измерить.** Уже заложено: pass-rate зрелых карточек, повторений на выученное слово, D7.

### 3.8 «Своё предложение» для зрелых слов — среднее / M или L

- **Что видит ученик.** Для слова с интервалом 21+ день: «Напиши своё предложение с этим словом — про себя». Без ИИ: после отправки показать образцовые примеры и спросить «похоже?». С ИИ: короткая проверка и исправление.
- **Почему.** Генерация (d = 0.40), связь с собой, компонент evaluation из ILH, продуктивная практика.
- **Почему только зрелые.** На новом слове это вредит запоминанию формы (Barcroft 2004).
- **Риски.** Без проверки ученик закрепит ошибку. ИИ — расходы и новая зависимость (по правилам проекта зависимости согласуются с владельцем). Уровень A1 ограничивает возможности писать.
- **Как измерить.** Точность `spelling` и `gap_fill` на этих словах через 30 дней против контрольных.

### 3.9 Связать практику с расписанием — среднее / M

- **Что менять.** Сейчас практика изолирована. Предложение — правило «как в игре»: ошибка в сочетании, предложении или диктанте приближает повторение целевых слов; верный ответ в продуктивном задании (диктант, сборка) можно засчитывать как прохождение ступени 6 лестницы.
- **Почему.** Иначе «использование» и «повторение» живут отдельно, и расписание не знает, что слово не применяется.
- **Риск.** Это отмена сознательного решения (docs/16 §0, тест `PracticeIsolationTest`). Нужен architect и согласие владельца. Минимальный безопасный шаг — только «приближение при ошибке» через тот же механизм, что `GameSrsAdjuster`.

### 3.10 Семьи слов и морфология — среднее / S код, M контент

- **Что видит ученик.** На зрелой карточке: «Из этой же семьи: teach → teacher, teaching». При первом слове с приставкой или суффиксом — короткая подсказка «-er = тот, кто делает».
- **Почему.** Средний эффект обучения морфологии; знание переносится на новые слова.
- **Риск.** На A1 мало производных слов; польза растёт к A2–B1.

### 3.11 Шаг «скажи вслух» — низкое–среднее / S

- **Что видит ученик.** После звука — «Повтори вслух» и кнопка «Сказал». Без распознавания речи.
- **Почему.** Эффект проговаривания, на L2 он больше.
- **Риск.** Проверить нельзя; в транспорте и на уроке неуместно — сделать отключаемым. Просить не на каждой карточке (эффект сильнее, когда вслух идёт часть слов).

### 3.12 Предтест нового слова — низкое–среднее / S

- **Что видит ученик.** Новое слово сначала без перевода: «Как думаешь, что это?» — затем ответ.
- **Почему.** Potts & Shanks (2014); заодно ловит уже известные слова, которые можно сразу выпустить с длинным интервалом.
- **Оговорка.** Эффект подтверждён на узнавании, не на вспоминании. Главная практическая польза — именно отсев известных слов.

### 3.13 Еженедельное задание «используй» — среднее / M

- **Что видит ученик.** Раз в неделю бот присылает 3–5 его зрелых слов и задание: ответить на вопрос, используя их.
- **Почему.** Направление «вывод со смыслом» из four strands, которого в продукте сейчас нет вовсе.
- **Риск.** Без проверки ценность ниже; с проверкой — это уже отложенный план «Говорим» (docs/17).

### 3.14 «Ложный друг» и «знакомое слово» — низкое–среднее / S

- Пометка на карточке: «Осторожно: magazine — это журнал, не магазин». Для интернационализмов — «Ты это уже знаешь» и ускоренный выпуск.
- Для узбекского списки придётся составлять с носителем: исследований с учениками я не нашёл.

### 3.15 Состав сессии и время — низкое / S

- Сначала повторения, потом новые слова (уже так).
- Напоминание по умолчанию вечером (сейчас 19:00 по Ташкенту — согласуется с данными о сне).
- Не поднимать дневную квоту новых слов: ограничитель — будущая нагрузка повторений.
- Серии: заморозки уже есть; не добавлять новых «наказаний» за пропуск.

### Порядок внедрения

1. **Без нового контента:** № 1, № 2, № 7, № 12, № 11, дешёвый вариант № 6. Это уже меняет метод.
2. **С минимальным контентом:** № 3 + поле «своя ассоциация» из № 4 + крючки для 100–150 самых трудных слов.
3. **Контентная волна:** № 5, полный № 4, № 10, № 14.
4. **Требует решений владельца и architect:** № 9, № 8 с ИИ, № 13.

### Общие метрики успеха

- **Удержание знаний на 30 день:** доля верных ответов на первом повторении с интервалом ≥ 30 дней.
- **Продуктивное вспоминание:** точность `spelling` на словах возрастом 30+ дней.
- **Применение:** точность `gap_fill` на невиданном предложении.
- **Цена:** число оценок на слово до интервала 21 день.
- **Честность самооценки:** доля случаев «Средне/Легко», после которых объективный ответ неверен.
- **Защитные:** D7, D30, длина сессии, доля выполнивших дневную цель.

## 4. Метод одним абзацем — для пользователей

> Мы не просим зубрить. Каждое слово ты сначала связываешь с чем-то знакомым — картинкой в голове, похожим словом, частью слова. Потом мы спрашиваем его у тебя именно тогда, когда ты начинаешь забывать: через день, через неделю, через месяц. Вспоминать труднее, чем перечитывать, — поэтому это и работает. И с каждым разом задание чуть сложнее: узнать слово, вспомнить его, написать, вставить в предложение, составить своё. Так слово перестаёт быть строчкой в списке и становится тем, чем ты пользуешься.

Чего в тексте обещать не стоит: «запомнишь навсегда», «в N раз быстрее», «метод подстроен под твой тип восприятия».

## 5. Чего не делать

- **«Стили обучения» (визуал, аудиал).** Pashler и др. (2008): доказательств, что подстройка под «стиль» помогает, практически нет. [Источник](https://digitalcommons.usf.edu/psy_facpub/1765/)
- **Перечитывание списков, режим «просто пролистать слова».** Низкая полезность по Dunlosky.
- **Зубрёжка всего урока за один присест.** Разнесение сильнее.
- **Новые слова пачкой из одной категории** (все цвета, все члены семьи, пары антонимов в один день).
- **Только тесты на выбор из вариантов.** Они тренируют узнавание; для продукции нужен ввод.
- **Дворец памяти и крючки-цифры** как функция продукта.
- **Мнемоника как главное обещание.** Это вспомогательный крючок, а не метод.
- **«Составь предложение» на первом знакомстве со словом.**
- **Растить интервал по верным ответам в игре и в выборе из вариантов** (в игре это уже соблюдено).
- **Наращивать бейджи и рейтинги ради вовлечённости** без контроля метрик учёбы.

## 6. Где доказательства слабые и что не удалось проверить

**Ограничение доступа.** Открыть напрямую удалось только GitHub. Сайты `docs.ankiweb.net`, Wiley, Cambridge, Springer, SAGE, PubMed/PMC, APS, eScholarship недоступны из этой сессии. Всё, что не помечено как «прочитано», взято из аннотаций и выдержек в результатах поиска.

**Прочитано напрямую:** руководство Anki (`leeches.md`, `deck-options.md`), README `srs-benchmark`, учебник `fsrs4anki`.

**Не подтверждено или подтверждено только вторично:**

- Atkinson & Raugh (1975): проценты (в литературе обычно 72 % против 46 %) и результат отложенного теста — не найдены в выдаче.
- Wang & Thomas (1995): аннотация самой статьи не получена; вывод о более быстром забывании — из их работы 1992 года и пересказов.
- Kim & Webb (2022): величины g — из вторичной цитаты.
- Webb (2007), сравнение пар и предложений: только библиографическая запись, результата нет.
- Nakata (2017), число вспоминаний: пересказ цитирующей статьи.
- FSRS «на 20–30 % меньше повторений»: только блоги; в бенчмарке сравнения с SM-2 в числах я не увидел (таблица превосходства дана картинкой).
- Carpenter & Olson (2012) о картинках: упоминание в выдаче без прямой ссылки.
- Symons & Johnson (1997): эффект 0.45 — из вторичного источника.
- Mazza и др. (2016): цифры за 6 месяцев — из пересказа; размеры выборки в пресс-релизах расходятся.
- Griffin & Harley (1996), Pagán & Nation (2019), обзор MacLeod о production effect, Krashen о narrow reading — не найдены; в отчёте на них не опираюсь.
- «10–12 встреч» — не подтверждено как порог; мета-анализ даёт только корреляцию.

**Темы, где сама наука слабая:**

- мнемоника в сочетании с SRS (прямых исследований не нашёл);
- отложенный эффект keyword method (противоречиво);
- узбекский язык: когнаты, ложные друзья, звуковые ассоциации — экспериментов нет;
- перемешивание для лексики;
- картинки против перевода;
- жест;
- предтест для вспоминания (а не узнавания);
- тревога из-за серий и вред геймификации в языковых приложениях;
- оптимальное число новых слов в день и потолок интервала.

**Что стоит проверить на своих данных в первую очередь** (данные уже есть, код писать почти не нужно): расхождение самооценки с объективным ответом у Pro-учеников; долю ошибок-перепутываний с дистрактором из того же урока; распределение `lapses` (сколько слов и у скольких учеников — «пиявки»).
