Задача 18.8e от координатора: браузерный e2e практики и баттла на НАСТОЯЩЕМ локальном API. `{TASK}` = `18-8e`. Порт API: 8010.

## Окружение
- Первым делом выполни шаги 0–6 из `docs/handoff/sprint18/prompts/18-env.md`: vendor, `.env`, `node_modules`.
- В ветке слиты:
  - соло-практика с исправлениями ревью (18.9);
  - сервер баттла (18.6 + 18.6b);
  - экраны баттла (18.6-T).
- Источник: `docs/16_PRACTICE_DESIGN.md` §14.4 (сценарии), §7 (API), §8 (баттл), §11 (TWA).

## Как поднять стенд
Всё временное — в `$S/e2e-18/`.
1. **База.** Отдельная SQLite: `touch .../e2e-18/e2e.sqlite`.
2. **Переменные окружения** — передавай их в команды, а не правкой `.env`:
   ```
   APP_ENV=local
   DB_CONNECTION=sqlite DB_DATABASE=<абс. путь>
   PRACTICE_ACCESS=pilot
   QUEUE_CONNECTION=sync CACHE_STORE=file SESSION_DRIVER=file
   TELEGRAM_BOT_TOKEN=123456:e2e-test-token
   APP_URL=http://127.0.0.1:8010
   ```
   Плюс то, что нужно для демо-сида — посмотри `DatabaseSeeder` и `.env.example`.
3. **Миграции и сид:** `php artisan migrate:fresh --seed --force`.
   - Демо-сиды, в том числе `PracticeDemoSeeder`: пилотный пакет 90 заданий, ученики демо-группы в пилоте, аудио диктантов через ffmpeg flite.
   - Если демо-сид не включён по умолчанию — найди переключатель.
   - Сделай двух демо-учеников друзьями: короткий PHP-скрипт в `e2e-18/` через `php artisan tinker --execute` или сервис дружбы проекта. Схему и прочие файлы не меняй.
4. **TWA.** Собери в `public/twa` — он в `.gitignore`, проверь `git check-ignore`. Сервер: `php artisan serve --port=8010` в фоне (TWA и API на одном origin). После прогона останови и удали `public/twa`, если до тебя его не было.
5. **Playwright** установлен глобально (`require('playwright')` работает из любой папки, Chromium предустановлен).
   - НЕ запускай `playwright install` и не добавляй пакеты.
   - В `.mjs` подключай через `createRequire(import.meta.url)('playwright')`.
   - Если не находит — `NODE_PATH` глобальных модулей (`npm root -g`).
6. **Запуск как в Telegram.**
   - `#tgWebAppData=…` — initData, ПОДПИСАННАЯ по правилам Telegram: `secret = HMAC_SHA256(key="WebAppData", msg=bot_token)`, `hash = hex(HMAC_SHA256(secret, data_check_string))`, `user.id` — `telegram_id` демо-ученика.
   - Плюс `tgWebAppThemeParams` светлой и тёмной темы — см. харнесс `.../scratchpad/visual-18-1t/shoot.cjs`.
   - `https://telegram.org/**` подменяй пустым скриптом, как в харнессе.
7. **Ускорение баттла.**
   - Сценарий `both_absent` требует `presence_grace_seconds = 5`. Если в `config/practice.php` это не настраивается из окружения, добавь ОДНУ строку `env('PRACTICE_BATTLE_PRESENCE_GRACE', 30)` с комментарием «ускорение для e2e / стенда» и опиши её в отчёте.
   - Другие ключи конфига не меняй.

## Что написать
`resources/twa/scripts/e2e/practice.mjs` (+ `README.md` рядом: как поднять стенд и запустить, одной страницей). Без изменений `package.json`. Скрипт:
- принимает `--base http://127.0.0.1:8010` и пути к данным учеников (telegram id);
- печатает шаги и итог PASS/FAIL по сценариям;
- снимки кладёт в каталог из аргумента (по умолчанию — scratchpad).

**Сценарии (docs/16 §14.4):**
1. **Соло.** Каждый из четырёх режимов от хаба урока до итогов: «Найди пары», «Подбери сочетание», «Собери предложение», «Слушай и пиши».
   - Диктант играет настоящий клип: в headless проверь загрузку blob и `<audio>`; звук не нужен.
   - Хотя бы одна ошибка нарочно.
   - Затем «Повторить ошибки».
   - Проверить:
     - итоги совпадают с ответами;
     - повторное открытие хаба показывает «Продолжить» при брошенной сессии;
     - после обрыва сети (Playwright `route.abort` на один ответ) повтор не меняет результат: вердикт и счёт те же, без 409 на экране.
2. **Баттл — два контекста браузера, два ученика.**
   - Приглашение из «Друзья» → принятие у второго → «Готов» ×2 → 5 раундов.
   - Один игрок в одном раунде не отвечает → таймаут.
   - У обоих одинаковые итоги и счёт.
3. **Перезагрузка** страницы в середине матча → матч продолжается с того же раунда.
4. **Фон:** эмуляция `visibilitychange` (hidden ~10 с → visible) → без потери матча.
5. **Сдача.**
6. **Оба закрыли** (оба контекста закрыты дольше grace) → `closed` / `both_absent` у обоих при следующем открытии.
7. **Снимки** экранов сессии (каждый режим: задание и разбор) и баттла (комната, раунд, разбор, итог):
   - 390 и 320 px;
   - светлая и тёмная темы.
   Просмотри их сам: обрезки, наложения, контраст.

## Правила
- Найденные ошибки приложения НЕ чини, кроме очевидной однострочной правки, и её — с объяснением. Опиши каждую: шаги, ожидаемое и фактическое, запрос/ответ из сети (`page.on('response')`), снимок, вероятное место в коде.
- Скрипт должен быть повторяемым: стенд с нуля → PASS на исправном коде. Если сценарий нестабилен по таймингу — ожидания по состоянию DOM и опросу, без `sleep`.
- Не трогай главный чекаут `/home/user/flash-cards` и `PROGRESS.md`. Коммить только `resources/twa/scripts/e2e/*` и (если понадобилась) строку конфига.

## Definition of Done
- Скрипт и README закоммичены в ветку worktree.
- Полный прогон: таблица сценариев PASS/FAIL, время.
- Найденные ошибки описаны.
- Снимки просмотрены, пути к ним указаны.
- Стенд остановлен, `public/twa` удалён.
- В отчёте: ветка и `git log --oneline`.
