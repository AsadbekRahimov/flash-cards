# Инструкция автору: «Форма слова» и «Найди ошибку» (x-файлы)

Технический проект — `docs/16` §5.6, §5.7, §15.1. Общие правила языка (ru / uz, «вы» / «Siz», латиница uz, ASCII-апостроф) — как в `TASK_BRIEF.md`.

## Файл

`database/data/practice/<курс>-xNN.json`, формат `lexiflow-practice/1`, `course` — slug курса. Два модуля (`2k-1` и `2k`) = 10 уроков × 6 заданий = 60.
Ключ: `<префикс>-mNN-lN-w1..3` (форма слова) и `-e1..3` (найди ошибку); префикс — `a1a2`, `b1`, `b2`, `c1`, `c2`. Уровень — по модулю (a1-a2: модули 1–10 — `A1`, 11–20 — `A2`).

## Общее

3 задания каждого типа на урок; целевые слова — из этого урока (`base` или ответ «Формы слова»; слово исправленного предложения «Найди ошибку»). Предложение естественное, одной мысли, ≤ 12 слов на A1–A2, ≤ 16 на C1–C2. `translation` — перевод всего **правильного** предложения; `explanation` — правило в 1–2 фразах на ru и uz, без «потому что так правильно». Оба поля обязательны на обоих языках.

## «Форма слова» (`word_form`)

```json
{ "key": "b1-m03-l2-w1", "type": "word_form", "lesson": {"stage": 3, "number": 2}, "level": "B1", "target_words": ["decide"],
  "text": "We need to make a ___ by Friday.", "base": "decide", "accepted": ["decision"],
  "translation": {"ru": "…", "uz": "…"}, "explanation": {"ru": "…", "uz": "…"} }
```

- Контекст однозначно требует **одну** часть речи и форму: `make a ___` → существительное; `She sings ___` → наречие.
- Уровни: A1 — множественное число, 3-е лицо, прошедшее, `-ing`; A2 — степени сравнения (`good → the best`: тогда `accepted` с артиклем, а в тексте его нет), `-ly`, `-er`/`-or`, `-ful`/`-less`; B1 — `-tion`/`-ment`/`-ness`/`-ity`, `-able`/`-ous`/`-al`/`-ive`, `un-`/`in-`/`dis-`; B2 — `im-`/`ir-`/`il-`, `-ance`/`-ence`, `-ant`/`-ist`/`-ee`, `en-`/`-ify`/`-ise`, двойная деривация; C1 — смена основы (`pronounce → pronunciation`), `mis-`/`over-`/`under-`/`counter-`; C2 — редкие академические формы, пары по смыслу (`economic`/`economical`).
- **Ловушки:** (1) второй верный ответ — перепишите контекст или перечислите все верные в `accepted` (до 4; первый — канонический): положительная и отрицательная форма, единственное и множественное, `-ed`/`-ing`; (2) варианты написания вне `resources/lexicon/en-us-gb.txt` (`judgement`/`judgment`) — в `accepted`; (3) ответ не должен стоять в самом тексте; (4) ответ не равен `base`; (5) ответ — не больше 3 слов, только буквы, апостроф, дефис; цифр нет.
- Опечаток режим не прощает: каждый ответ должен быть настоящим словом (чекер проверяет лексиконом).

## «Найди ошибку» (`error_hunt`)

```json
{ "key": "b1-m05-l1-e1", "type": "error_hunt", "lesson": {"stage": 5, "number": 1}, "level": "B1", "target_words": ["interested"],
  "text": "I am very interested *on* modern art.", "options": ["in", "at", "for"], "correct": ["in"],
  "translation": {"ru": "…", "uz": "…"}, "explanation": {"ru": "…", "uz": "…"} }
```

- Ровно **одна** ошибка, типичная для носителя русского и узбекского; ошибочное слово помечено `*…*` (целое слово, пунктуация снаружи: `*informations*.`). 4–16 слов, лучше 7–12.
- Уровни: A1 — `have/has`, `is/are`, `a/an`, `in/on/at` со временем, `I/me`, `his/her`; A2 — неправильное прошедшее (`buyed`), `much/many`, `some/any`, предлоги места, `gooder`; B1 — формы времени, зависимые предлоги, `make/do`, ложные друзья (`magazine`, `fabric`, `accurate`, `sympathetic`, `artist`); B2 — `affect/effect`, `rise/raise`, `lie/lay`, `its/it's`, прилагательное вместо наречия; C1 — коллокации (`make a crime` → `commit`), `principal/principle`, сослагательное; C2 — `imply/infer`, `continual/continuous`, `fewer/less`, `who/whom`.
- **Ловушки:** (1) вторая «ошибка» — перечитайте предложение без помеченного слова: всё остальное безупречно; спорное (split infinitive, `data is`) не использовать; (2) помеченное слово не должно быть верным в другом прочтении (`I *lay* on the beach yesterday` — верно!); (3) ровно один верный вариант: неверные дают **явно** неверное предложение; (4) ошибочное слово не среди вариантов; (5) только замена слова (вариант из двух слов допустим: `*go*` → `to go`), «лишнее» и «пропущенное» слово не поддерживаются; (6) ошибка в первом слове — **все три** варианта с заглавной, иначе первые буквы трёх вариантов одного регистра: единственный вариант с другой первой буквой выдаёт ответ (`I` среди строчных вариантов не в начале предложения — тоже; чекер и импорт считают это ошибкой); (7) не больше 16 слов.

## Проверка

```bash
php docs/content-authoring/check_practice.php --modules=M1,M2 database/data/practice/<курс>-xNN.json
```

до `60 tasks checked, 0 errors`; каждый WARN прочитать. Затем — проход редактора по каждому заданию («докажи, что задание неверно»), и чекер ещё раз. Носитель языка читает файл после этого: контент импортируется черновиком.
