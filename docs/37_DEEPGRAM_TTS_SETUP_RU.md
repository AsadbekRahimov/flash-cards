# Озвучка через Deepgram: пошаговая инструкция

Это основной способ озвучки слов, примеров и диктантов (решение владельца от 25.11.2026). Google Cloud TTS остаётся запасным вариантом — [27_GOOGLE_TTS_SETUP_RU.md](27_GOOGLE_TTS_SETUP_RU.md). Как устроен код — [26_AUDIO_TTS_PLAN_RU.md](26_AUDIO_TTS_PLAN_RU.md) §10.

> Названия кнопок в консоли Deepgram могут меняться. Если кнопка называется иначе — ищите по смыслу.

## Что получится

```
новое слово / импорт / правка ──► очередь tts ──► Deepgram (голос Aura-2) ──► mp3 ──► ваш сервер или R2
ученик открывает карточку ──► https://ваш-домен/audio/<хеш>.mp3
```

- Каждый текст озвучивается **один раз**, в фоне, заданием очереди.
- Ученики к Deepgram не обращаются.
- Пока файла нет, Mini App говорит голосом телефона.
- Свои колоды учеников не озвучиваются (голос телефона).

## Сколько стоит

| Что | Сколько |
|---|---|
| Цена Deepgram Aura-2 | 0,03 $ за 1 000 символов |
| Бесплатный кредит при регистрации | 200 $, карта не нужна |
| Весь первый прогон (слова, примеры, диктанты, с запасом) | ≈ 550 000 символов ≈ 16,5 $ |
| Контрольный набор `audio:sample` (один голос) | ≈ 1 000 символов ≈ 0,03 $ |

Важно:

- Кредит **разовый**. Он не обновляется каждый месяц, как у Google.
- Поэтому в приложении предел тоже не месячный, а **общий**: `DEEPGRAM_TTS_CHAR_LIMIT`, по умолчанию 6 000 000 символов (≈ 180 $ из 200 $).
- Счётчик хранится в базе (таблица `tts_usage_months`, строка `dgtotal`) и сам не обнуляется.
- Предел исчерпан — озвучка останавливается. Новые слова ждут. Пополнили счёт в Deepgram — поднимите предел (см. «Если кончились деньги»).

## Шаг 1. Регистрация

1. Откройте `https://console.deepgram.com/signup`.
2. Зарегистрируйтесь рабочей почтой (не личной: доступ потом можно передать).
3. Карту не вводите — 200 $ дают и без неё.
4. После входа откроется проект по умолчанию. Его и используем.

## Шаг 2. API-ключ

1. В консоли: слева **API Keys** (или **Settings → API Keys**).
2. **Create a New API Key**.
3. Имя: `lexiflow-tts`.
4. Права (роль): выберите самую узкую, которую даёт консоль. Обычно это **Member** — ей можно синтезировать речь, но нельзя управлять проектом и ключами. Роли **Owner** и **Admin** не берите.
   - Если консоль предлагает отметить отдельные права (scopes) — оставьте только использование речи (`usage:write` / «speech»).
5. Срок действия: «никогда» или длинный срок. Если ключ истечёт, озвучка остановится с кодом `tts_auth_failed`.
6. Нажмите **Create**. Скопируйте ключ **сразу** — второй раз его не покажут.

Ключ — это пароль:

- не кладите его в репозиторий, в чат, в почту;
- храните только в `.env` на сервере (в Coolify — в переменных приложения);
- при подозрении на утечку удалите ключ в консоли и создайте новый (шаг «Смена ключа»).

Приложение никогда не пишет ключ в логи, в ошибки и в Sentry.

## Шаг 3. Переменные `.env`

Минимум:

```dotenv
TTS_DRIVER=deepgram
DEEPGRAM_API_KEY=ваш-ключ
TTS_VOICE=aura-2-thalia-en
```

Все переменные Deepgram:

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `TTS_DRIVER` | — | `deepgram` |
| `DEEPGRAM_API_KEY` | пусто | ключ из шага 2. Пусто — озвучки нет (`tts_service_not_configured`), `/health/ready` показывает `"tts": "degraded"` |
| `TTS_VOICE` | `aura-2-thalia-en` (если пусто и драйвер `deepgram`) | голос Deepgram. Имя Google (`en-US-…`) не подходит: ошибка `tts_voice_unsupported` |
| `DEEPGRAM_TTS_CHAR_LIMIT` | `6000000` | общий предел символов на весь кредит; `0` — синтез запрещён |
| `DEEPGRAM_TTS_RATE_PER_MINUTE` | `150` | запросов в минуту на все воркеры вместе; задание ждёт до 30 с |
| `DEEPGRAM_TTS_BIT_RATE` | `48000` | качество mp3: `48000` или `32000`. Смена = другой звук, поднимите `TTS_AUDIO_VERSION` |
| `DEEPGRAM_TTS_MAX_CHARS` | `2000` | самый длинный текст одного запроса (предел Deepgram — 2 000 символов) |
| `DEEPGRAM_TTS_TIMEOUT` | `20` | секунд ждать ответа |
| `TTS_AUDIO_VERSION` | `1` | входит в имя файла; поднять = переозвучить всё |
| `TTS_QUEUE_ATTENTION_SIZE` | `3000` | строка «Очередь озвучки» в `/admin`, когда заданий больше |

Где лежат файлы и по какому адресу их видят ученики (диск `public` на сервере, адрес `https://ваш-домен/audio/…`, или Cloudflare R2) — **не зависит от Deepgram**. Это описано в [27_GOOGLE_TTS_SETUP_RU.md](27_GOOGLE_TTS_SETUP_RU.md): часть B (R2), C2 (переменные `TTS_AUDIO_DISK`, `TTS_PUBLIC_DISK_AUDIO_URL`, `AUDIO_*`), C3 (воркер `--queue=low,tts`). Без R2 ничего настраивать не нужно: файлы лягут на сервер.

Переменные Google (`GOOGLE_TTS_*`, `TTS_MONTHLY_CHAR_LIMIT`, `TTS_RATE_PER_MINUTE`) при Deepgram не нужны. Их можно оставить пустыми.

**Применить правку `.env`.** В Docker: `docker compose -f docker-compose.prod.yml up -d` (контейнеры пересоздадутся и перечитают `.env`). В Coolify — передеплой. Без Docker: `php artisan config:cache` и `php artisan queue:restart`.

Ниже команды пишутся коротко: `php artisan …`. В Docker это `docker compose -f docker-compose.prod.yml exec app php artisan …`, в Coolify — терминал контейнера `lf-app`.

## Шаг 4. Проверка ключа и голоса

```bash
php artisan audio:sample
```

Что делает:

- озвучивает ≈ 30 трудных слов и фраз (короткие слова, омографы, сокращения, числа, даты, два диктанта);
- сразу, без очереди;
- кладёт файлы в `storage/app/audio-samples/<голос>/`;
- печатает таблицу «текст → файл → размер» и в конце `Deepgram characters used: N of 6 000 000`.

Если в таблице вместо файлов коды ошибок — смотрите таблицу «Что делать при ошибках».

Скопировать файлы к себе (Docker):

```bash
docker compose -f docker-compose.prod.yml cp app:/var/www/html/storage/app/audio-samples ./audio-samples
```

## Шаг 5. Сравнить голоса на слух

Одной командой записать несколько голосов, каждый в свою папку:

```bash
php artisan audio:sample --voices=aura-2-thalia-en,aura-2-andromeda-en,aura-2-arcas-en,aura-2-apollo-en,aura-2-asteria-en,aura-2-athena-en
```

- Шесть голосов ≈ 6 000 символов ≈ 0,18 $.
- Не больше 10 голосов за запуск.
- Папки: `storage/app/audio-samples/aura-2-thalia-en/`, `…/aura-2-andromeda-en/` и т. д.
- Один голос: `php artisan audio:sample --voice=aura-2-apollo-en`.

Слушайте прежде всего **короткие слова** (`a`, `I`, `go`, `the`, `eye`): не обрезано ли начало, нет ли вопросительной интонации.

| Голос | Какой |
|---|---|
| `aura-2-thalia-en` | женский, американский, чёткий (по умолчанию) |
| `aura-2-andromeda-en` | женский, американский, мягкий |
| `aura-2-asteria-en` | женский, американский |
| `aura-2-athena-en` | женский, американский, спокойный |
| `aura-2-apollo-en` | мужской, американский |
| `aura-2-arcas-en` | мужской, американский |

Транскрипции в курсах американские — берите американский голос.

Выбрали — запишите в `.env`: `TTS_VOICE=<голос>` и примените правку (шаг 3).

**Смена голоса позже — это полный повторный прогон** (новые имена файлов, все символы заново). Поэтому выберите до шага 6.

## Шаг 6. Озвучить всё

Сначала один курс на пробу:

```bash
php artisan audio:pregenerate <slug-курса>
```

Подождите несколько минут. Затем всё:

```bash
php artisan audio:pregenerate --all
```

- Ставит в очередь слова и примеры всех курсов (кроме своих колод учеников).
- Только слова: `--only=words`. Только примеры: `--only=examples`.
- Диктанты озвучиваются сами, при новой версии задания.
- Пока очередь длинная, в `/admin` висит «Очередь озвучки» — это нормально.

## Шаг 7. Контроль

Покрытие курса:

```bash
php artisan audio:coverage <slug-курса> --verify
```

- `--verify` проверяет сами файлы.
- Итог: `<slug>: N of M active words voiced (X%)` и строка `Examples: …`.

Строки в `/admin`, блок «Требуют внимания»:

| Строка | Когда | Что делать |
|---|---|---|
| «Deepgram · расход кредита» — «Израсходовано X % предела кредита» | от 90 % `DEEPGRAM_TTS_CHAR_LIMIT` | проверить баланс в консоли Deepgram (**Billing**) |
| то же — «Предел кредита исчерпан» (красная) | предел достигнут | см. «Если кончились деньги» |
| «Deepgram · озвучка остановлена» (красная) | Deepgram отклонил ключ или оплату | см. таблицу ошибок, затем `audio:sample --clear-halt` |
| «Очередь озвучки» | в очереди `tts` больше 3 000 заданий | при массовом прогоне — нормально; иначе проверить воркер `queue-low` |
| `<slug> · озвучка` | у курса озвучено меньше 95 % слов | `audio:pregenerate <slug>` |

Каждую ночь в 02:30 UTC команда `audio:reconcile` сама ставит в очередь то, что не озвучено.

## Что делать при ошибках

Код ошибки виден в таблице `audio:sample`, в `php artisan queue:failed`, у диктантов — в колонке ошибки озвучки.

| Код | Что значит | Что делать |
|---|---|---|
| `tts_service_not_configured` | `DEEPGRAM_API_KEY` пуст или опечатка в `TTS_DRIVER` | задать ключ (шаг 3) |
| `tts_voice_unsupported` | `TTS_VOICE` — не голос Deepgram (например, остался `en-US-AriaNeural` или голос Google) | `TTS_VOICE=aura-2-thalia-en` или оставить пустым |
| `tts_auth_failed` | 401: ключ неверный, удалён или истёк | новый ключ (шаг 2), затем `audio:sample --clear-halt` |
| `tts_forbidden` | 403: у ключа нет прав на синтез речи | ключ с ролью Member (шаг 2), затем `audio:sample --clear-halt` |
| `tts_payment_required` | 402: на счёте Deepgram кончились деньги | пополнить счёт, затем `audio:sample --clear-halt` |
| `tts_credit_limit_reached` | достигнут `DEEPGRAM_TTS_CHAR_LIMIT` (предел в приложении) | см. «Если кончились деньги» |
| `tts_rate_limited` | 429 (Deepgram просит реже) или своё ограничение темпа | ничего: задание повторится само (5 попыток) |
| `tts_service_failed` | Deepgram недоступен (5xx) или оборвалась связь | повторится само; если массово — проверить доступ сервера к `api.deepgram.com` |
| `tts_service_bad_audio` | ответ без звука | повторится само |
| `tts_text_too_long` | текст длиннее 2 000 символов | сократить текст диктанта; длинные примеры в очередь не попадают вовсе |
| `tts_request_rejected` | Deepgram отклонил запрос (400) | проверить текст и `TTS_VOICE` |
| `tts_audio_not_stored` | Deepgram ответил, а диск не принял файл | права на папку или ключи R2 (docs/27 C8), затем `php artisan queue:retry all` |

**Маркер остановки.** После `tts_auth_failed`, `tts_forbidden` или `tts_payment_required` приложение на 10 минут перестаёт обращаться к Deepgram. Все задания сразу завершаются тем же кодом. Так очередь не шлёт тысячи заведомо неудачных запросов. Ночная сверка в это время ничего не ставит.

Исправили ключ или пополнили счёт — снимите маркер и проверьте одной командой:

```bash
php artisan audio:sample --clear-halt
```

Затем верните упавшие задания:

```bash
php artisan queue:retry all
```

(или `php artisan audio:pregenerate --all` — поставит только неозвученное).

**`/health/ready` показывает `"tts": "degraded"`** — пуст `DEEPGRAM_API_KEY` или опечатка в `TTS_DRIVER`. Сайт при этом работает.

## Если кончились деньги

Сначала остановится наш предел (`tts_credit_limit_reached`, ≈ 180 $), а не счёт Deepgram — это запас на 20 $.

1. В консоли Deepgram **Billing**: посмотрите остаток, пополните счёт (тут уже нужна карта).
2. Поднимите предел в `.env`. Счётчик не обнуляется, поэтому новый предел = уже потрачено + новые символы. Пример: потрачено 6 000 000, пополнили на 100 $ (≈ 3 300 000 символов) → `DEEPGRAM_TTS_CHAR_LIMIT=9000000`.
3. Примените правку (шаг 3).
4. Слова доозвучит ночная сверка. Сразу — `php artisan audio:pregenerate --all`.
5. Диктанты с ошибкой — кнопка «Сгенерировать аудио заново» в `/admin`.

Сколько потрачено: последняя строка `audio:sample` (`Deepgram characters used: …`) или строка `dgtotal` таблицы `tts_usage_months`.

## Смена ключа

1. Создать новый ключ (шаг 2).
2. Заменить `DEEPGRAM_API_KEY` в `.env`, применить правку (шаг 3).
3. `php artisan audio:sample --clear-halt` — проверка.
4. Удалить старый ключ в консоли Deepgram.

## Вернуться на Google

Код Google не удалён. `TTS_DRIVER=google` и настройка по [27_GOOGLE_TTS_SETUP_RU.md](27_GOOGLE_TTS_SETUP_RU.md). Голос Google другой — это полный повторный прогон.

## Что не проверено

- Координатор сверил по документации Deepgram (25.11.2026): адрес и формат запроса `/v1/speak`, заголовок `Authorization: Token`, предел **2 000 символов** на запрос у Aura-2 (длиннее — ответ 413), ответ 429 при превышении лимита запросов. **Не сверены:** код 402 при закончившемся кредите, число параллельных запросов на бесплатном тарифе, права ключа. Их покажет первый запуск `audio:sample` на сервере.
- Сеть разработчика не пустила к `developers.deepgram.com` (25.11.2026): предел 2 000 символов на запрос, коды ответов (401, 402, 403, 429) и права ключей взяты из постановки задачи, а не сверены по документации. Предел запроса настраивается (`DEEPGRAM_TTS_MAX_CHARS`).
- Настоящий вызов Deepgram в тестах не делается. Первый настоящий вызов — `audio:sample` на сервере.
